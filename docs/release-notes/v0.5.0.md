See at a glance which account a session uses, how much of it is left, and whether chottag is prod or dev.

## What's new

- **A logo.** chottag has a mark, `c»`: a C with a » reaching out from its
  top end, like a tag. It is blue for your normal install and amber for a
  dev one. It is in `assets/logo/`, and it shows in the status line and
  the cmux pill.
- **Status line, v2.** `chottag statusline` now prints the serving
  account's usage and next reset, and how many accounts are still
  available:
  `c» B · 5h 42% · 7d 18% · ↻ 19:00 · 3/4 ok`.
  A limited account turns its figures red; `NO_COLOR` turns colour off.
  The other states are `c» down`, `c» off` and `c» up`. `--json` adds
  `label`, `fiveHourPct`, `sevenDayPct`, `resetsAt`, `okAccounts` and
  `rotationAccounts`.
- **A cmux sidebar pill.** Inside cmux, the same line shows as a pill for
  the workspace. It updates only when the line changes.
- **An install label.** `chottag setup --label NAME` names an install (for
  example `dev`). Its notifications read `chottag · dev: …`, and
  `chottag status` shows `(dev)`. An install without a label looks exactly
  as before.
- The plugin skill offers the `statusLine` snippet, and adds it only after
  you say yes.
