A fix for the usage ledger on Linux.

## Fixed

- **No blank lines in the usage ledger on Linux.** When the daemon's live recorder and a `chottag stats` import appended to the same `usage/` file at once, a blank line could be written. Readers skipped it, so no figure in `chottag stats` was wrong. Each append now holds a lock on the file while it checks the file's end and writes.
