The Claude Code plugin is renamed to `chottag@c-hottag`.

## What's new

- **The plugin is `chottag`, from the marketplace `c-hottag`, and its skill
  is `chottag`.** Install it with `claude plugin install chottag@c-hottag`,
  and invoke the skill as `/chottag:chottag`. The old id was
  `claude-hottag@hottag` (skill `/claude-hottag:hottag`).

- **Fixed: a `claude` launch with no daemon running could start a chain
  of processes.** On macOS the shim saw itself as `…/bin/claude` and
  started the daemon under that name, so the new process ran as the shim
  and started another. The shim now starts the daemon from the resolved
  `chottag` binary, and never from a binary named `claude`. v0.4.0 is
  affected. Until you update, run `chottag daemon start` before starting
  `claude` from a new shell.

## Upgrade note

If you installed the plugin under its old id, remove that one and install
the new one. From a Claude Code session outside a chottag clone:

```sh
claude plugin uninstall claude-hottag@hottag
claude plugin marketplace remove hottag
claude plugin marketplace add HaiNNT/c-hottag
claude plugin install chottag@c-hottag
```

The binary, your accounts and `~/.chottag` are unaffected.
