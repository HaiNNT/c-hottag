Community files for contributors and issue reporters, and a terms-of-use note in the README.

## What's new

- Issues and forks are welcome; pull requests are by invitation only
  (`CONTRIBUTING.md`). A pull request from anyone without write access is
  closed automatically, with a link to that page.
- New: `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `ROADMAP.md`, `NOTICE` (also in
  every release archive), `CHANGELOG.md`, and issue forms for bugs, route
  drift and feature ideas.
- The README's policy note is now "Terms of use and risk": it quotes the
  Claude Code legal page's credential rule directly, says plainly what
  chottag's proxy does, and sends you to Anthropic's own terms to decide
  for yourself; no warranty. The FAQ's "Is this allowed?" adds which
  behaviours look least "ordinary", warns against switching to another
  account to get around a suspension, a ban or a hold, and points a held
  account at Anthropic's own review and appeal page.
- [Getting started](../getting-started.md) covers installing from a private
  repository (`gh auth login`, then a token-carrying `gh api` fetch of
  `install.sh`), for sharing chottag before it is public.

## Fixed

- **cmux: session hooks run again for a `claude` started through
  chottag.** chottag's `claude` came first on PATH and started Claude Code
  directly, so cmux's wrapper and its hooks were skipped. Inside a cmux
  surface, chottag now hands the launch to cmux's wrapper once, with the
  proxy settings already set; cmux's wrapper then starts chottag again,
  which starts Claude Code. See `docs/known-limitations.md` for the cases
  where the hand-off is skipped.
- **Connector calls no longer raise false route-drift notices at session
  start.**
