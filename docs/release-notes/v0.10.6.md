Session names use the repo folder, not the subfolder you are in.

## Fixed

- **A session is named after a subfolder (`src 17:38`).** On `main` (or a detached HEAD), a session is named `<folder> HH:MM`. The folder was the session's current directory, so a session that had moved into `platform/apps/shell/src` before its second prompt was named `src`. It is now the folder of the repo (or of the worktree) that holds the current directory, and the current directory's own folder only outside git. A name already set after a subfolder of the repo is fixed at the session's next prompt, keeping its time.
