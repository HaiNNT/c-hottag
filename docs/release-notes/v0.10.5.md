Session names put the topic first.

## Changed

- **The topic comes first in a session name.** A name was `<branch> · <title>`, or `<folder> HH:MM · <title>` on `main`, so a narrow tab showed only the folder and time. It is now `<title> · <branch>` (`<title> · <folder> HH:MM`). A session named by 0.10.4 is renamed in the new order at its next prompt. The name is still at most 80 characters: a long title is shortened and the branch is kept. A session with no title yet is still named by its branch alone, and a session you named yourself is never renamed.
