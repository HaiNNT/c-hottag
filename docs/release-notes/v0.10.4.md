Session names get their topic again, and follow a session into a worktree.

## Fixed

- **A session stays `<folder> HH:MM` and never gets a topic.** chottag named a session at its first prompt and added Claude Code's generated title later. But Claude Code generates a title only for a session that has no name yet, so the title never came. chottag now does nothing at the first prompt and names the session at the second, as `<branch> · <title>` (`<folder> HH:MM · <title>` on `main`). A session that still has no title then is named by its branch alone. A session already named by 0.10.3 or older keeps its name without a topic.
- **A session that enters a worktree keeps its old name.** The name was fixed at the first naming. While the name is still the one chottag set, each prompt now checks the branch again: a session that moved to another branch is renamed after it at its next prompt, and keeps its title. Back on `main` it keeps the last branch. A session you named yourself is still never renamed.
