The guide for Claude Code sessions matches the public repository and
agrees the setup with the user before logging accounts in.

## What's new

- [For Claude Code](../for-claude-code.md): the repository is public, so
  any `gh` login can install; no collaborator access is needed. Releases
  of `HaiNNT/c-hottag` before v0.4.7 were built while it was private, have
  no build attestation, and `install.sh` refuses them: install v0.4.7 or
  later.
- The guide now checks that chottag started (`status`, `doctor`, with the
  two checks a first install is expected to fail), then asks the user
  three short questions before logging in: which accounts and their names,
  which one is pinned for Remote Control, connectors and artifacts, and
  whether the pinned account also pays for prompts. It logs the pinned
  account in first and sets it with `chottag remote`.
- Getting started: the private-repository section now covers only a
  private fork.
