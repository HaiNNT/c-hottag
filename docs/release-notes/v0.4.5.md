## What's new

- README: the first feature now reads "Switching never breaks Remote
  Control, connectors or artifacts": most switchers swap your whole login,
  so those claude.ai features break after a switch; chottag pins them to
  one account (`chottag remote <name>`) and switches only the account that
  pays for your prompts.
- The comparison table's first column is that pin: chottag has it built
  in; claude-swap, clauth, caam and CCSwitcher switch by swapping Claude
  Code's whole login, so they don't (claude-swap through its cswap-pin
  add-on). [docs/comparison.md](../comparison.md) cites each tool's own
  description of how it switches.
