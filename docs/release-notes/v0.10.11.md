## Added

- **Ultra evidence.** Anthropic's verified Ultra accounts have no 5-hour limit and a separate weekly limit for Fable, and chottag does not yet know the exact headers. It now records both facts and changes nothing else: `chottag status --json` marks an account `noFiveHour` when its responses carry a 7-day window but no 5-hour window (cleared when a 5-hour window reappears), and lists under `daemon.unknownLimitClaims` the binding limit claim of each refusal chottag does not classify, with a count and a last-seen time (at most 8 names). Such a refusal is still not treated as a limit. `chottag doctor` shows both in a new info row, `plan-evidence`, which appears only while there is something to show. The daemon log notes the first sighting of each, naming the account or the claim and nothing else. If you see a claim name there, please report it. Both are kept in the status cache across daemon restarts: the row stays until a 5-hour window reappears (`noFiveHour`) or, for claims, until the status cache is removed. See [`chottag status`](../commands.md#chottag-status) and [`chottag doctor`](../commands.md#chottag-doctor).
