chottag now calls the Max 20x tier Ultra, following Anthropic's rename.

## Changed

- **Max 20x is shown as Ultra.** `chottag plan NAME ultra` sets it, and `chottag plan`, `chottag auto`, `chottag status`, `chottag doctor` and the usage text show `ultra` where they showed `max20x`. `chottag auto set 5h.ultra 95` works like `5h.max20x`. `max20x` is still accepted as the old name. The machine value is unchanged: `state.json` and every `--json` field keep `max20x`, so a daemon left on an older version during a deferred restart still reads the account as 20 times a Pro. See [`chottag plan`](../commands.md#chottag-plan).
