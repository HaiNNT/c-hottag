chottag now reports your usage (`chottag stats`), and plan takes a monthly price for the value comparison.

## Added

- **`chottag plan NAME --price N`.** Sets the monthly USD price chottag compares an account's usage against (`0` resets to the plan's list price: pro 20, max5x 100, ultra 200). `chottag plan NAME TIER` keeps a price you set. `plan --json` gains `price` (the effective price, or `null`) and `priceSource` (`list`, `set` or `none`).
- **`chottag stats`.** Shows tokens and API-equivalent dollars overall, per model and per account; each account's value against its plan price and its 7-day peak; and keep, upgrade, downgrade or cancel verdicts for each account and for the whole set. `--by day|month`, `--since`, `--until`, `--account`, `--weeks`, `--json`, `--html [--out PATH]` and `--reimport`. Every figure is explained in `docs/stats.md`.
- **A usage ledger in `usage/`.** The daemon records each message's model and token counts and a utilization snapshot per account about every ten minutes, and imports Claude Code's transcripts (read-only, including Home's) once a day. Only numbers and model ids are kept: never a prompt, a reply, a tool result, a path or a session id. Raw records are kept for 90 days, daily totals and utilization for good. Delete it with `rm -r ~/.chottag/usage`. Utilization history, and so verdicts, start when you install this version.
- **`chottag doctor` `usage-ledger` row.** Whether `usage/` is writable and when transcripts were last imported. Information only.
- **`stats` details.** Accounts show `$ per 1% of a Pro` (`usdPerUnitPct` in `--json`) and their weekly peaks (`B  weekly peak %: 41 63 88 97`); an account's price is pro-rated from its first day in the ledger (at least one day), shown as `since DATE` (`from` in `--json`); a `--since` within 31 days gives a by-day series unless you pass `--by`; an unreadable transcript file or folder is skipped with a `usage_import_skipped` warning instead of stopping the import. `import.json` keeps a hash of each transcript's path, never the path. Haiku 5.5's long-prompt price tier is not applied to daily totals (its cost can be understated for prompts over 100K tokens).
