See at a glance whether a Claude Code session goes through chottag.

## What's new

- `chottag statusline` prints one short segment for Claude Code's status
  line: `chottag: <serving account>`, `chottag: down` or `chottag: off`
  (a session on your normal login). Add it to your own `statusLine`; see
  [Getting started](../getting-started.md#which-sessions-use-chottag).
- `chottag status` shows `live sessions: N` (and `daemon.liveSessions` in
  `--json`), so another terminal can confirm a session started through
  chottag.
- The guides say plainly that only sessions started after the install use
  chottag, and how to move a running one over (exit, open a new terminal,
  `claude --continue`).
