chottag now tells you about a new release from whichever check finds it first, and the daemon checks four times a day instead of once.

## Changed

- The first check that finds a newer release posts the desktop notice, `chottag <version> is available. Run: chottag update`: the daemon's, or `chottag update --check`. No check posts it again for that version, even across a daemon restart; the next newer release posts again. With notifications off the version still counts as told, so turning them on later does not replay it. The record is a small file, `run/update-notified`, so the daemon and the command agree even when they run at the same moment.
- The daemon checks for a new release about every 6 hours (plus up to 15 minutes of jitter), four requests a day to `api.github.com` instead of one. The first check is still 2 minutes after the daemon starts, and automatic install still waits for a release to be 24 hours old.
