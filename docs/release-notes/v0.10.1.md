Built with Go 1.27.2, which fixes four standard-library security advisories in v0.10.0's binaries.

## Security

- **Go 1.27.2.** v0.10.0 was built with Go 1.27.1, which has four `net/http` advisories, three of them HTTP/2 server crashes: GO-2026-6611, GO-2026-6612, GO-2026-6613 and GO-2026-6617. chottag's proxy listens only on `127.0.0.1` and needs the session's secret, so the exposure was small, but the binaries now carry the fix.

## Notes

- No behaviour change from v0.10.0.
