An install-and-manage guide written for a Claude Code session acting on a user's behalf.

## What's new

- [Install and manage chottag for a user](../for-claude-code.md): an
  ordered, copy-pasteable page for a Claude Code session installing or
  managing chottag for someone. It installs without a clone (a clone of
  this repo blocks installer and most `chottag` runs, by design), covers a
  private repository's git credentials for the plugin, sends the user to
  the terms before installing, and says that only a Claude Code session
  started after the install is routed through chottag.
- The README's "For Claude Code" section, `CLAUDE.md` and the plugin
  skill's "not installed" step now point at that page instead of
  repeating its steps.
