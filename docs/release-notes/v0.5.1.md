## Changed

- The docs and the plugin skill now start from your own status line.
  `chottag statusline` gives it a segment to add, or fields through
  `--json`. Pointing `statusLine` at chottag is only for someone with no
  status line yet. Use `statusline` rather than `status --json` for this:
  only `statusline` knows whether the session running it goes through
  chottag.
- `chottag statusline` no longer changes anything: the cmux sidebar pill is now opt-in with `--cmux`.
